Class Matrix

Object operator []

Access:read write
arguments are indexes to array, number of arguments must be equal to number of arguments put to constructor

Object function clone()

void function fill( value)

constructor ()

arguments are dimensions, eg. new Matrix(4,3) creates 2-dimensional array with 4 rows(0..3) and 3 columns(0..2), valid indexing is [0..3,0..2]

Object function search( what)

searches what, if found, returns MultiIndex, if not found, returns null
